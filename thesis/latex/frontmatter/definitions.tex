\chapter{Definitions}\label{definitions}

The following terms are used in this work:

\textbf{Bounding box} --- a rectangular region in pixel coordinates defined by its top-left corner \((x_1, y_1)\) and bottom-right corner \((x_2, y_2)\), used to localise a detected object within an image.

\textbf{Crown} --- the visible upper part of a tree as observed from above in satellite or aerial imagery, approximated by a polygon mask in this work.

\textbf{CVAT (Computer Vision Annotation Tool)} --- an open-source web-based tool for manual annotation of images and video, used in this project to label tree crowns as polygon masks and bounding boxes.

\textbf{CIoU loss (Complete IoU loss)} --- an extension of the plain IoU loss that, in addition to the box-overlap term, penalises the centre-point distance between predicted and ground-truth boxes and the inconsistency of their aspect ratios. CIoU is the default box-regression loss of YOLOv8 and is used throughout the YOLO branch of the present work.

\textbf{COCO (Common Objects in Context)} --- the public benchmark dataset and the evaluation protocol it defines. In this work the term refers to the evaluation protocol --- \texttt{pycocotools.cocoeval.COCOeval} --- used to compute Box and Mask mAP@50 / mAP@50:95 on the M14 validation set across all model branches.

\textbf{DeepForest} --- a Python library for tree-crown detection built on a RetinaNet single-stage detector, pre-trained on National Ecological Observatory Network (NEON) lidar data over forested sites in the United States.

\textbf{Focal loss} --- a classification loss introduced by RetinaNet that down-weights the contribution of well-classified examples through a \((1 - p_t)^{\gamma}\) modulating factor, so the gradient is dominated by difficult cases. Focal loss is the classification loss of the DeepForest branch in the present work.

\textbf{GeoJSON} --- an open standard format for encoding geographic data structures using JSON, used in this project to export tree inventories with per-crown polygon geometries in WGS-84.

\textbf{GeoTIFF} --- a TIFF image file format that embeds geographic metadata (coordinate reference system, affine transform) directly in the file, enabling automatic pixel-to-geographic-coordinate conversion.

\textbf{Ground Sampling Distance (GSD)} --- the distance on the ground corresponding to one pixel in a satellite or aerial image, expressed in metres per pixel.

\textbf{Instance segmentation} --- a computer-vision task that simultaneously detects individual object instances and predicts a pixel-level binary mask for each instance, as opposed to semantic segmentation (per-pixel class labels without instance identity) or bounding-box detection (boxes only).

\textbf{M14 (14-image merged validation set)} --- the dedicated cross-model validation set constructed in this work for apples-to-apples comparison between all model branches. It contains 14 source images (4 v1 + 5 v2 + 5 v3) and 702 polygon annotations, generated by \texttt{ml/build\_14img\_val\_coco.py} and stored as \texttt{yolov\ train\ dataset/annotations\_merged\_14img\_val.json}. See Section 3.7.1.

\textbf{mAP (mean Average Precision)} --- the primary metric for object detection, defined as the mean of per-class Average Precision values; mAP@50 uses an IoU threshold of 0.5 to determine whether a predicted box matches a ground-truth box. mAP@50:95 averages the AP at ten IoU thresholds from 0.50 to 0.95 in increments of 0.05.

\textbf{Mask R-CNN} --- a two-stage instance-segmentation network that extends the Faster R-CNN detector with a fully-convolutional mask head running in parallel with the bounding-box regression head. In the present work the \texttt{maskrcnn\_resnet50\_fpn\_v2} variant is used.

\textbf{SAM 2 (Segment Anything Model 2)} --- a second-generation foundation model for class-agnostic image segmentation released by Meta AI in 2024, capable of producing precise object masks from box or point prompts without task-specific fine-tuning.

\textbf{Tiled inference} --- the practice of partitioning a large input image into overlapping fixed-size tiles, running the model independently on each tile, and merging the per-tile predictions into a single global result via Non-Maximum Suppression.

\textbf{WBF (Weighted Box Fusion)} --- an ensemble strategy that replaces Non-Maximum Suppression by averaging the coordinates of overlapping bounding boxes from multiple detectors, weighted by their confidence scores.

\textbf{WGS-84} --- the World Geodetic System 1984, the standard coordinate reference system used by GPS and most web mapping services, representing positions as latitude and longitude in decimal degrees.

\textbf{YOLOv8-seg} --- the instance-segmentation variant of the YOLOv8 single-stage object detector by Ultralytics, which adds a prototype mask head to the standard detection architecture to produce per-instance polygon masks alongside bounding boxes.
